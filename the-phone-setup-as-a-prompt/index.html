The Phone Setup, As a Prompt You Can Paste

September 23, 2026

A while back I wrote Maybe the Phone Is the Setup — about building real features from a six-inch screen while a Mac mini does the heavy lifting. A friend read it and asked the obvious follow-up: what do I actually need to copy this?

So here’s the whole thing. Not the philosophy this time — the parts list, and a prompt.

What the machine does, and what you doLink to heading

The trick only looks like magic. An always-on Mac runs Claude Code, the repo, and the local database. Tailscale tunnels you in. Your phone is just the seat you’re sitting in — the model does the writing, the machine does the running, and what’s left for you (review, decide, redirect) fits a phone fine.

Everything below is in service of that one arrangement: phone → Claude app → Claude Code on an always-on machine → repo + local database + a way to view it and ship it.

The accounts and hardware (the part no prompt can do for you)Link to heading

Some of this needs a human with a credit card and a browser. Get these first — Claude can’t sign you up.

Three tiers, so you can stop wherever you wantLink to heading

You don’t have to do all of it. Each tier stands on its own:

  • Local — repo + toolchain + Docker + local Supabase. You can run, test, and screenshot on the machine.
  • + Phone — add Tailscale, and you can open and test the live dev site from your phone.
  • + Ship — add gh auth (push to main → the deploy pipeline runs) and a Supabase CLI login (query the prod database, deploy edge functions).

The promptLink to heading

Install Claude Code, open it inside an empty folder on the machine, and paste this. It reads the target repo’s own docs and follows them, and it stops and asks you to run anything that needs a login.

Two footnotesLink to heading

  • Swap in your own repo. The prompt leans on a project’s own README.md, CLAUDE.md, and package.json scripts, so it works for any SvelteKit + Supabase repo — just hand Claude the clone URL and it follows that repo’s docs.
  • The pairing is the linchpin. The machine has to stay on and awake, and the Claude mobile app has to be connected to that machine’s Claude Code session. Everything else is just toolchain.

That’s it. The pieces aren’t exotic — a cheap always-on computer, a tunnel, a good model in the middle. The model is the part that changed. The rest has been sitting there for years, waiting for the seat to move to wherever you are.
